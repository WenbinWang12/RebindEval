Research project · controlled study

Does Muon’s advantage in associative memory extend to reasoning?

Abstract

Muon Reasoning studies what changes when a model must fit a familiar computation, reuse it under new values, bind renamed entities, or compose two learned steps. The design separates memorized answers from the use of a learned rule.

The question has two parts.

A score difference is an observation. The project asks whether the difference survives controlled changes and what kind of computation could explain it.

01 / separate

Fit from reuse

Matched probes keep the computation fixed while changing the information available at inference.

02 / compare

Source from optimizer

Source and optimizer pairs distinguish effects inherited from pretraining from effects that arise during adaptation.

03 / inspect

Behavior from mechanism

Component arms, spectra, prefix rescue, and role-wise probes move from an aggregate score toward an intervention.

A matched protocol for learning and transfer.

The experimental recipe is designed before the result. Each extension carries a scale label, source manifest, learning-rate decision, and evaluation contract.
