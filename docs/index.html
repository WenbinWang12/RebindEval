What is being tested next.

Follow-up experiments move from observation to localization, then to mechanism and boundary conditions.

Does the gap travel?

Scale-matched VarTrace, iGSM, BioFacts, TwoHop, GSM-Symbolic, and coverage variants widen the evidence base without collapsing source and optimizer into one comparison.

Current release surface

Design files and compact analysis notes are available in the repository. Raw checkpoints and row-level data remain outside the first public commit.

Where does it happen?

Component arms, spectral summaries, prefix rescue, and role-wise probes narrow the search from an aggregate score to the parts of the network and the stages of inference.

Matched comparisons

Every extension carries its own design, source manifest, learning-rate decision, and scale label.

What could cause it?

Weight-difference spectra and controlled interventions test whether a behavioral difference is aligned with component geometry, update magnitude, or the use of current inputs.

Interpretation rule

A mechanism claim requires an intervention or a convergent diagnostic. A score difference alone remains an observation.

A release that keeps the trail intact.

The public surface is intentionally small. It should be easy to inspect before it becomes large.

Design before result

Each new scale or experiment starts with a frozen design and an explicit protocol.

Hashes beside claims

Manifests, code snapshots, and evaluation outputs carry enough identity to reproduce the comparison.

Preliminary means preliminary

Ongoing runs stay marked as ongoing until the analysis and cleanup pass are complete.
